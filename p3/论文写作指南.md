## 一、本题的定位与写作主线

问题3 是问题2 的**多级推广**：2 道工序、8 个零配件、3 个半成品、1 个成品，共 **16 个 0-1 决策变量**（8配件检测+3半成品检测+1成品检测+3半成品拆解+1成品拆解），策略空间 2¹⁶=65536。

写作主线：**建立"自底向上的级联期望递推模型"（质量传递×期望成本），全枚举 65536 种策略求全局最优，蒙特卡洛模拟交叉验证，给出决策方案与指标。**

模型体系一致性是本题最大的加分点：**问题3 是问题2 公式的逐级嵌套推广**（一级单元的公式原样复用），论文务必点明这一递推结构。

## 二、建模思路（必须写清的部分）

### 2.1 级联质量传递（附录1 的推广）
- 配件 j 进入装配次品率 eⱼ = pⱼ(1−xⱼ)（检测后为0）；
- 半成品 i 实际不合格率 qᵢ = 1 − ∏(1−eⱼ)·(1−p_h)（配件不合格 或 装配工艺不合格）；
- 半成品输出质量由 yᵢ 决定（检测→合格输出；不检测→次品率 qᵢ 传递）；
- 成品实际不合格率 q_f = 1 − ∏(1−e_hᵢ)·(1−p_f)，e_hᵢ = qᵢ(1−yᵢ)。

### 2.2 级联期望成本（以"服务一个客户"为单位，口径B）
- 配件层：初装成本 Cⱼ = (1−xⱼ)cⱼ + xⱼ(cⱼ+dⱼ)/(1−pⱼ)（含重购）；回收件再处理 Dⱼ = xⱼ(dⱼ+cⱼpⱼ)/(1−pⱼ)（免采购）；
- 半成品层（yᵢ=1 时检测拦截，不合格件拆解或丢弃重做，循环期望收敛）：
  Eᵢ = [ΣCⱼ + a_h + d_h + qᵢ·zᵢ·(ΣDⱼ − ΣCⱼ + f_h)]/(1−qᵢ)
  （关键：首轮配件 ΣCⱼ，后续循环轮回收件 ΣDⱼ——两者的差必须体现在公式中）
  回收半成品再处理（成品拆解循环中，稳态混合下次品率=qᵢ，首轮直接检测）：
  Rᵢ = [d_h + qᵢ·(a_h + zᵢΣDⱼ + (1−zᵢ)ΣCⱼ + zᵢf_h)]/(1−qᵢ)
  yᵢ=0 时：Eᵢ = ΣCⱼ + a_h，Rᵢ = 0（质量直接传递）；
- 成品层（zf=1 拆解循环；zf=0 报废后重新采购再生产——口径B）：
  zf=1：成本 = ΣEᵢ + [a_f + y_f·d_f + q_f·(f_f + ΣRᵢ)]/(1−q_f)
  zf=0：成本 = [ΣEᵢ + a_f + y_f·d_f]/(1−q_f)
  收入：y_f=1 → s；y_f=0 → s − q_f·r/(1−q_f)。

### 2.3 求解方法
- 2¹⁶ = 65536 策略**全枚举**（每策略 O(1) 评估），天然全局最优、无局部最优问题；
- 蒙特卡洛模拟（N=20万）验证：最优策略误差 0.06%，全部对比策略误差 ≤0.65%——解析模型完全正确。

## 三、求解结果（正文核心）

**最优策略（利润 66.09 元/件合格品）**：

| 层级 | 决策 | 值 |
|:---|:---|:---|
| 零配件（8个） | 全部检测 x=11111111 | 检测费仅1~2元，拦截10%次品划算 |
| 半成品（3个） | 全部不检测、不拆解 y=000, z=000 | 检测费4元+拆解6元，不如让成品环节兜底 |
| 成品 | 检测（y_f=1）+ 拆解（z_f=1） | 售价200元，保证卖出的合格；拆解费10元回收半成品 |

指标：期望收入 200.00 − 期望成本 133.91 = **66.09 元/件**；
成品实际不合格率 q_f = **34.39%**（级联：配件10%×3 + 半成品10%×3 + 成品10%）；
期望生产轮数 1/(1−q_f) ≈ 1.52。

**基准策略对比（论文表格）**：

| 策略 | 利润 | 说明 |
|:---|:---:|:---|
| ★最优 | **66.09** | 配件全检测 + 成品检测拆解 |
| 全部检测+全部拆解 | 53.61 | 半成品检测4元×3+拆解6元×3 过贵 |
| 全部检测+不拆解 | 37.12 | 报废重做配件成本高 |
| 全部不检测+成品拆解 | −43.36 | q_f=71.8% 循环灾难 |
| 全部不检测 | −241.54 | 质量失控 |

### 决策依据（必须写出）
1. **配件必检测**：检测费 1~2 元 vs 次品配件造成的级联损失（10% 次品率下每件次品配件平均造成 ~0.3 件成品不合格），检测性价比极高；
2. **半成品不检测**：半成品检测（4元）+拆解（6元）成本高于"让次品传递到成品环节、由成品检测+拆解统一兜底"的成本——**质量控制在最下游集中进行更经济**；
3. **成品检测+拆解**：售价高（200元），必须保证卖出合格品；拆解费仅10元，回收半成品再装配的期望成本远低于重新采购；
4. **质量级联（图2）**：配件检测后 100% 合格入装 → 半成品 90% → 成品 65.61%——质量逐级流失，靠下游检测拦截。

## 五、模型讨论与评价（加分项）

1. **递推结构的普适性**：本模型可推广到任意 m 道工序、n 个零配件（把每一级视为一个"单元"，自底向上套用同一组公式）——正是题目"对 m 道工序、n 个零配件重复问题2"的要求，务必写明；
2. **口径B 一致性**：与问题2 相同，以"每服务一个客户"为单位，拆解/报废两分支口径统一（调换要求）；
3. **稳态混合假设**：回收半成品质量按总体分布重采样；若严格追踪同一件次品，循环可能无界，现实中企业会设循环上限——模型改进方向；
4. **与问题4的衔接**：次品率由抽样获得后，q 系列成为随机变量，决策需考虑抽样误差（置信区间/敏感性）。
