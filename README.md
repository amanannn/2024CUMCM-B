# 2024 CUMCM Problem B: 生产过程中的决策问题

2024年高教社杯全国大学生数学建模竞赛 B 题的完整解题项目（往年题练习）。

## 项目结构

```
├── B题.pdf / B题_Claude_Friendly.md   # 题目原文与可读版本
├── CLAUDE.md                          # 项目规范与工作流程
├── 论文写作总纲.md                     # 全卷写作骨架（摘要/图表索引/口径清单）
├── 方法学总结.md                       # 各题方法-特点-缺点总表
├── plot_style.py                      # 统一科研绘图风格（Nature 风）
├── p1/  抽样检测方案                   # 判定可靠度读法 n=29/n=22 + SPRT + 信度敏感性
├── p2/  两零配件生产决策               # 期望利润解析模型（口径B）+ 16策略枚举 + MC验证
├── p3/  多级生产决策                   # 级联递推 + 2^16全枚举 + 翻转检验 + 决策规则
└── p4/  抽样-决策一体化                 # 贝叶斯 EVSI 框架 + 批量敏感性 + 稳定性检验
```

## 核心方法

| 问题 | 方法 | 核心结果 |
|:---|:---|:---|
| 1 | 精确二项分布假设检验（判定可靠度读法） | 拒收 n=29 / 接收 n=22，通式 n=⌈ln(1−信度)/ln(1−p₀)⌉ |
| 2 | 期望利润解析模型 + 16 策略全枚举 + 蒙特卡洛验证 | 6 情形全局最优决策表（利润 12.97~21.68 元/件） |
| 3 | 自底向上级联递推 + 2¹⁶ 全枚举 | 配件全检测+成品检测拆解，利润 66.09 元/件 |
| 4 | 贝叶斯抽样-决策一体化（EVSI） | 最优抽样量由批量与信息价值内生决定 |
